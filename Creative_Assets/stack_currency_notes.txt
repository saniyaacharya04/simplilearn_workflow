The CurrencyStack asset is constructed as a programmatically defined stack of Indian ₹500 currency notes, where every visual element — the base platform, individual notes, and their decorative details — is built using Manim's mobject primitives and grouped into a unified `VGroup` structure. The entire stack is self-contained within the `CurrencyStack` class, which inherits from `VGroup`, allowing it to be positioned, scaled, and animated as a single object. A global color palette (`C_BKG`, `C_SEC`, `C_TER`, `C_PRI`, `C_TXT`) is defined at the top of the file and used consistently across all elements, ensuring visual coherence without hardcoding hex values throughout the class.

The CrispText helper is a utility function defined outside the class to produce sharp, readable text at small sizes. Manim's `Text` mobject can appear slightly blurry when rendered at small font sizes, so `CrispText` addresses this by creating the text at double the intended size (`font_size=size*2`) and then calling `.scale(0.5)` on it, which forces Manim to render at higher resolution before scaling down. For multi-line inputs, the text is split on `\n`, each line is created as a separate `Text` object, and the resulting list is arranged vertically using `.arrange(DOWN, buff=0.1)` inside a `VGroup`. The `weight="BOLD"` is enforced unconditionally through `kwargs`, meaning all CrispText output is always bold regardless of what the caller passes.

The base platform is the foundation of the stack, constructed as a `RoundedRectangle` with a width of `2.55`, a height of `0.06`, and a corner radius of `0.02` — making it a very thin, nearly flat slab. It is filled with the gray color `C_TER` and given a dark stroke using `C_SEC`. To create a sense of depth and grounding, a shadow copy of the platform is made using `.copy()`, colored black with `0.3` opacity, and shifted `DOWN * 0.1 + RIGHT * 0.1` to simulate a light source coming from the upper left. Both the shadow and the platform are grouped into `self.base_platform_group`, which ensures the shadow always travels with the platform during any transformation or animation.

The individual note construction is handled by an inner function `make_note(idx, ref_mobject, buff_val)` defined inside `__init__`. Each note is built as a `RoundedRectangle` with width `2.4`, height `1.0`, and corner radius `0.05`, filled with the orange color `C_PRI`. On top of this base shape, five decorative elements are added: a "RESERVE BANK OF INDIA" text label positioned at the top of the note using `get_top() + DOWN * 0.15`; a white `Ellipse` representing the security oval on the right side, positioned using `get_right() + LEFT * 0.5`; a "500" denomination text at the bottom left using `get_left() + RIGHT * 0.35 + DOWN * 0.2`; a narrow green `Rectangle` acting as a vertical security thread, centered slightly left of the note's center using `LEFT * 0.25`; and a Rupee symbol (`₹`, Unicode U+20B9) rendered using `CrispText` with the `FreeSans` font, which is specified explicitly because it reliably renders the Rupee glyph correctly. All six elements — the base note and its five details — are grouped into `note_group`. A shadow is then created from the base note alone (not the full group) and shifted `DOWN * 0.05 + RIGHT * 0.05`, forming `single_note = VGroup(note_shadow, note_group)`.

The stacking and positioning logic relies on Manim's `.next_to()` method rather than absolute coordinates. Each note is positioned relative to the one below it using `single_note.next_to(ref_mobject, UP, buff=buff_val)`, where `buff_val` is set to `-0.8` for all notes after the first. The negative buffer causes each note to overlap the previous one by `0.8` units, creating the visual illusion of a thick physical stack rather than notes floating above each other. The first note uses the `base_platform_group` as its reference object with a buffer of `0`, placing it directly on top of the platform. Each note also receives a slight alternating tilt via `.rotate(0.01 * (-1)  idx)`, where the `(-1)  idx` alternates between `+1` and `-1` depending on whether the index is even or odd, producing a subtle left-right wobble that makes the stack look naturally imperfect rather than mechanically aligned.

The build_anim method constructs and returns a staggered entrance animation using Manim's `LaggedStart`. It first adds a `FadeIn` for the `base_platform_group`, then iterates over `self.note_objects` in order from bottom to top, appending a `FadeIn(note, shift=UP * 0.2)` for each note. The `shift=UP * 0.2` makes each note appear to rise slightly upward as it fades in, reinforcing the sense of physical stacking. All these animations are passed into `LaggedStart` with a `lag_ratio=0.15`, meaning each animation begins `0.15` seconds after the previous one starts rather than all playing simultaneously, producing a wave-like bottom-to-top reveal.
